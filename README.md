WORLD NEWS · MONDAY, 23 NOVEMBER 2026

Eight illustrated news panels cover climate talks, Asian markets, Libya,
Denmark, Israeli coalition talks, spaceflight, golf and health workers in
DR Congo. Four briefs cover Chinese margin requirements, US holiday travel,
the Golden Horse awards and South Korea's education minister.

The image was generated from scratch using the built-in image generator,
without reference images, then resized and quantized using Pillow 11.1.0.
The final asset is a 1024 × 1024 PNG with a 256-color palette.

## Run

Node 22.18 or later; only Node's standard library is required.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program validates the bundled PNG and writes identical bytes to
`entry.png` in `MAKEFUN_OUTPUT_DIR` (default `/output`). It needs no network
or installed dependencies. Pillow is only used during asset preparation.
